## Введение {#введение}

CRM «TryNeuro» — система для управления записью клиентов. Поддерживает три типа бизнеса:

- **Автосервис (AUTO)** — запись к мастерам, учёт автомобилей
- **Бьюти-услуги (BEAUTY)** — запись к специалистам, заметки к визиту
- **Аренда (RENT)** — бронирование объектов (кабинеты, оборудование)

Система состоит из:

- **Веб-приложение** — адаптивный интерфейс для всех устройств
- **Telegram-боты** — 4 AI-бота для записи через Telegram
- **Telegram-уведомления** — напоминания о визитах (через Pyrogram)

## Роли и доступы {#роли-и-доступы}

| Роль | Доступ | Описание |
|---|---|---|
| **ADMIN** | `/admin` + `/manager` + `/employee` | Полный доступ ко всем функциям |
| **MANAGER** | `/manager` + `/employee` | Управление записями, клиентами, услугами. Без управления филиалами и AI |
| **EMPLOYEE** | `/employee` | Только свои смены и записи |
| **CLIENT** | `/client` | Личный кабинет: запись, отмена, уведомления |

## Личный кабинет клиента {#личный-кабинет-клиента}

Доступ: **/client** (требуется регистрация/вход)

### Регистрация

1. Перейти на `/register-client`
2. Ввести email, пароль, название компании (ваш филиал)
3. Подтвердить регистрацию
4. Войти в личный кабинет

### Возможности

- **Выбор филиала** — в верхней панели выбрать нужный филиал (если у компании их несколько)
- **Просмотр расписания** — таймлайн с доступными слотами
  - В AUTO/BEAUTY — колонки по мастерам
  - В RENT — колонки по объектам аренды
- **Создание записи** — нажать на свободный слот → выбрать услугу → подтвердить
  - Услуги фильтруются по типу филиала (в RENT видны только RENT-услуги)
  - При записи в RENT филиале объект аренды привязывается автоматически
- **Просмотр записи** — нажать на свою запись в таймлайне (помечена «Ваша запись»)
- **Отмена записи** — в модалке деталей записи нажать «Отменить эту запись»
- **Настройка уведомлений** — в профиле можно настроить напоминания о визитах

## Панель администратора {#панель-администратора}

Доступ: **/admin** (требуется вход с ролью ADMIN)

### Расписание (таймлайн) {#расписание}

Основной экран — таймлайн с колонками сотрудников или ресурсов (зависит от ниши филиала).

**Управление:**
- Выбор даты — стрелки «‹» и «›» или клик на дату для возврата к сегодня
- Выбор филиала — дропдаун в верхней панели
- **Клик по пустому слоту** → создание новой записи
- **Клик по записи** → просмотр/редактирование

**Фильтры (в разработке):** onlyBusyStaff, onlyWorkingStaff

**Создание записи:**
1. Нажать на пустой слот
2. В модалке заполнить:
   - Клиент (поиск по имени, или создать нового)
   - Услуга (поиск по названию)
   - Длительность (пресеты 15/30/45/60/90/120 мин)
   - Сотрудник(и) — можно добавить нескольких
   - Ресурс (для RENT)
   - Комментарий
3. Нажать «СОХРАНИТЬ»

**Редактирование записи:**
- Изменить клиента, услугу, время, сотрудника, статус
- Если запись групповая (несколько сотрудников) — выбрать режим «Применить ко всей группе» или «Только текущую»

### Сотрудники {#сотрудники}

CRM → Сотрудники

**Управление:**
- Создать — имя, специальность, email, пароль, филиалы
- Редактировать — изменить данные, привязать к филиалам
- Фото профиля — загрузить/удалить (отображается в таймлайне)
- График работы — настройка смен (день недели, время начала/конца, перерыв)
- Деактивация — сотрудник не отображается в таймлайне

**График (Shift):**
- День недели (1 = понедельник ... 7 = воскресенье)
- Время начала/конца работы
- Время начала/конца перерыва
- Привязка к филиалу

### Клиенты {#клиенты}

CRM → Клиенты

- Поиск по имени или телефону
- Просмотр истории записей
- Редактирование: имя, телефон, теги (автомобиль/объект)
- Ручное создание записи из карточки клиента

### Услуги {#услуги}

CRM → Услуги

**Создание/редактирование:**
- Название
- Длительность (мин)
- Стоимость: не указана / фиксированная / диапазон цен
- **Ниша** — для каких филиалов доступна услуга:
  - «Все ниши (общая услуга)» — видна везде (NULL)
  - AUTO / BEAUTY / RENT — только в филиалах этой ниши
- После сохранения услуга появляется в формах записи

### Ресурсы {#ресурсы}

CRM → Ресурсы

Только для RENT-филиалов. Объекты аренды: кабинеты, оборудование, залы.

**Управление:**
- Создание: название, описание, привязка к филиалу
- Редактирование: название, описание, филиал
- **Фото** — загрузить/заменить/удалить (отображается в таймлайне и в карточке списка)
- Удаление ресурса

### Филиалы {#филиалы}

CRM → Филиалы

**Управление:**
- Название, адрес, часовой пояс
- **Ниша филиала** — AUTO / BEAUTY / RENT (определяет интерфейс)
- Список филиалов отображается в селекторе на всех экранах

### Отчёты {#отчёты}

CRM → Отчёты (в разработке)

### Настройки Telegram {#настройки-telegram}

CRM → Настройки → Telegram

Настройка интеграции с Telegram для уведомлений:

- **Токены ботов** — настройка 4 AI-ботов (через переменные окружения)
- **Pyrogram сессия** — авторизация по phone для отправки уведомлений клиентам
  - Ввод номера телефона → получение кода → авторизация
  - Сессия переживает перезапуски (авто-восстановление)

### AI Настройки {#ai-настройки}

CRM → Настройки → AI

Настройка AI-бота для каждого пользователя:

- **Провайдер** — GigaChat (облачный) / Локальная LLM (Qwen 2.5 3B)
- **API ключ** — для GigaChat (auth key)
- **Модель** — название модели (для локальной LLM)
- Настройки применяются к конкретному сотруднику

### Напоминания о возврате {#напоминания-о-возврате}

CRM → Напоминания

Автоматическая рассылка напоминаний клиентам, которые давно не были:

- Настраиваемый период (дней с последнего визита)
- Отправка через Telegram (Pyrogram)
- Логи отправки в консоли бэкенда

## Ниши (Автосервис / Бьюти / Аренда) {#ниши}

### Что такое ниша

Ниша определяет тип бизнеса филиала. Влияет на:

| Аспект | AUTO | BEAUTY | RENT |
|---|---|---|---|
| Колонки в таймлайне | Мастера | Мастера | Ресурсы |
| Фото в колонках | Фото мастеров | Фото мастеров | Фото ресурсов |
| Лейбл «Автомобиль/Объект» | Автомобиль | Заметка к визиту | Объект аренды |
| Плейсхолдер тегов | Марка, госномер... | Пожелания, длина... | Номер объекта... |
| Доступные услуги | AUTO + общие | BEAUTY + общие | RENT + общие |

### Как настроить

1. **Филиал** → редактор филиала → выбрать нишу
2. **Услуги** → редактор услуги → выбрать нишу (или «Все ниши»)
3. **Ресурсы** → добавить объекты аренды для RENT-филиалов
4. **Фото ресурсов** → открыть ресурс → загрузить фото

### Авто-переключение

Таймлайн автоматически переключается при выборе филиала:
- Выбран AUTO/BEAUTY → колонки сотрудников
- Выбран RENT → колонки ресурсов

## Часто задаваемые вопросы {#faq}

### Не могу войти в систему

Проверьте email и пароль. Если забыли пароль — обратитесь к администратору компании.

### Не вижу филиал в списке

Филиал не назначен вашей учётной записи. Обратитесь к администратору.

### Не могу создать запись — услуги пустые

Убедитесь, что для выбранного филиала созданы услуги с соответствующей нишей (или общие услуги). Если услуги есть, но не отображаются — проверьте нишу филиала и нишу услуг.

### В чём разница между AUTO и RENT?

- AUTO — классический автосервис: мастера оказывают услуги, каждый мастер имеет график
- RENT — аренда объектов: клиент бронирует объект (кабинет, оборудование), а не мастера

### Как загрузить фото ресурса?

CRM → Ресурсы → Открыть ресурс → вверху формы секция фото → «Загрузить» → выбрать файл.

### Как добавить несколько сотрудников на запись?

В форме создания/редактирования записи есть раздел «Исполнители». После выбора первого сотрудника нажмите «+ Добавить исполнителя...».

### Как отменить групповую запись?

При редактировании записи с групповым идентификатором появится выбор:
- «Применить ко всей группе» — отменить/изменить для всех сотрудников
- «Только текущую запись» — отменить/изменить только для одного сотрудника

### Почему я не вижу клиентский портал?

Клиентский портал находится по адресу **/client**. Если вы администратор — войдите через обычную форму входа, затем откройте `/client` в другой вкладке или выйдите и зайдите как клиент.

### Как настроить уведомления в Telegram?

CRM → Настройки → Telegram:
1. Авторизуйте Pyrogram (введите номер телефона, подтвердите код)
2. Настройте токены ботов (если ещё не настроены)
3. В карточке клиента включите «Напоминание» и укажите время за сколько часов напоминать

### Что такое «Напоминания о возврате»?

Автоматическая рассылка клиентам, которые не были давно. Настраивается в CRM → Напоминания. Отправляется через Telegram.

### Как работает AI-бот?

Четыре Telegram-бота (`@NineCRM_AI_1_bot` … `_4`) отвечают на вопросы клиентов, могут:
- Искать контакты, услуги, сотрудников
- Создавать/изменять/отменять записи
- Искать информацию в базе знаний компании
- Поддерживают ReAct цикл (до 15 итераций)

Выбор провайдера: CRM → Настройки → AI → Провайдер (GigaChat или Локальная LLM).
