# 🧪 Тестирование ролей в системе

## 📋 Обзор

Этот набор тестов проверяет корректность работы системы контроля доступа на основе ролей в приложении.

## 🏗️ Архитектура тестов

### Бэкенд тесты (JUnit + Spring Boot Test)
- **Расположение:** `backend/src/test/java/com/tryneuro/backend/security/RoleBasedAccessTest.java`
- **Что проверяет:** 
  - Доступ к эндпоинтам согласно ролям
  - Запрещенный доступ между ролями
  - Корректность JWT аутентификации
  - Работа SecurityConfig

### Фронтенд тесты (Playwright + Svelte)
- **Расположение:** `frontend-svelte/tests/roles.spec.js`
- **Что проверяет:**
  - UI навигация между ролями
  - Редиректы при попытке доступа к запрещенным маршрутам
  - API запросы с правильными токенами
  - Выход из системы

## 🚀 Запуск тестов

### 1. Быстрый запуск всех тестов
```bash
# Из корневой директории проекта
node test-runner.js
```

### 2. Запуск бэкенд тестов
```bash
cd backend
mvn test -Dspring.profiles.active=test
```

### 3. Запуск фронтенд тестов
```bash
cd frontend-svelte
npm install
npm run test:e2e:install  # Установка Playwright браузеров
npm run test:e2e          # Запуск тестов
npm run test:e2e:ui       # Запуск с UI интерфейсом
npm run test:e2e:debug    # Отладочный режим
```

| Роль | Эндпоинты бэкенда | Маршруты фронтенда | Права доступа |

## 🎯 Что проверяют тесты

### ✅ Позитивные сценарии
- Администратор может получить доступ ко всем эндпоинтам
- Менеджер может получить доступ к своим эндпоинтам
- Сотрудник может получить доступ к своим эндпоинтам
- Корректная аутентификация и авторизация
- Правильные редиректы после логина

### ❌ Негативные сценарии
- Менеджер не может получить доступ к админским функциям
- Сотрудник не может получить доступ к функциям менеджера
- Сотрудник не может получить доступ к админским функциям
- Неавторизованный пользователь не может получить доступ к защищенным ресурсам
- Неверный токен отклоняется

### 🔄 API тесты
- Правильные HTTP статусы (200, 403, 401)
- Корректная работа заголовков Authorization
- Валидация параметров запросов
- Обработка ошибок
