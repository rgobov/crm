# 🌍 План интернационализации приложения

## 📋 Обзор

Текущее состояние: приложение полностью на русском языке. Нужно добавить поддержку мультиязычности для международного рынка.

## 🎯 Цели

1. **Поддержка 3 языков:**
   - 🇷🇺 Русский (текущий - базовый язык)
   - 🇺🇸 Английский (международный)
   - 🇰🇿 Казахский (региональный)

2. **Полная локализация:**
   - UI фронтенда
   - Сообщения бэкенда
   - Email уведомления
   - Документация API

## 🏗️ Архитектура интернационализации

### **Фронтенд (Svelte)**
```
frontend-svelte/
├── src/
│   ├── lib/
│   │   ├── i18n/
│   │   │   ├── index.js          # Экспорт функций
│   │   │   ├── ru.json          # Русский
│   │   │   ├── en.json          # Английский
│   │   │   └── kk.json          # Казахский
│   │   └── stores/
│   │       └── locale.js         # Хранилище языка
│   └── +layout.svelte            # Выбор языка
```

### **Бэкенд (Spring Boot)**
```
backend/
├── src/
│   └── main/
│       └── resources/
│           ├── i18n/
│           │   ├── messages_ru.properties    # Русский
│           │   ├── messages_en.properties    # Английский
│           │   └── messages_kk.properties    # Казахский
│           └── application.properties
└── pom.xml
```

## 🚀 План развертывания

### **Разработка**
```bash
# Создаем ветку
git checkout -b feature/i18n

# Устанавливаем зависимости
cd frontend-svelte && npm install svelte-i18n
cd backend && mvn clean install
```

### **Тестирование**
```bash
# Запускаем с разными языками
# Русский (по умолчанию)
npm run dev

# Английский
npm run dev --lang=en

# Казахский
npm run dev --lang=kk
```

### **Продакшен**
```bash
# Сборка с поддержкой i18n
npm run build

# Тестирование продакшена
npm run preview
```

## 🔄 Поддержка и развитие

### **Добавление нового языка**
1. Создать файл `messages_{lang}.properties`
2. Добавить переводы в JSON файл фронтенда
3. Обновить компонент переключения языков
4. Протестировать новый язык

### **Обновление переводов**
1. Изменить соответствующие файлы
2. Запустить скрипт проверки полноты переводов
3. Протестировать измененные строки
4. Обновить документацию

## 📝️ Риски и митигация

### **Риски**
- **Увеличение размера бандла** → Ленивая загрузка
- **Сложность поддержки** → Автоматизация проверки
- **Проблемы с RTL** → Тестирование казахского
- **Неполные переводы** → Скрипты валидации

### **Митигация**
- Использование современных инструментов i18n
- Автоматизированная проверка полноты
- Тщательное тестирование
- Четкая документация
