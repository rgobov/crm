# Инструкция: Ниши в CRM (Автосервис / Бьюти / Аренда)

## Что такое ниша

Ниша определяет тип бизнеса, которым занимается **филиал**. От неё зависят:
- Какие колонки отображаются в таймлайне (сотрудники или объекты аренды)
- Какие услуги видны клиентам и админам при записи
- Лейблы и иконки в формах (например, «Автомобиль/Объект» или «Заметка к визиту»)

Три ниши: **AUTO** (автосервис), **BEAUTY** (бьюти-услуги), **RENT** (аренда объектов).

---

## Для администратора

### 1. Настройка ниши филиала

CRM → Филиалы → Редактировать филиал → выбрать нишу в поле «Ниша филиала».

- При создании нового филиала ниша устанавливается как **AUTO** (по умолчанию).
- Нишу можно изменить в любое время.

### 2. Настройка услуг

CRM → Услуги → Редактировать/Создать услугу.

В редакторе услуги появилось поле **«Ниша (для каких филиалов)»**:

- **Все ниши (общая услуга)** — услуга видна в филиалах любой ниши (рекомендуется для общих услуг вроде «Консультация»).
- **AUTO / BEAUTY / RENT** — услуга видна только в филиалах соответствующей ниши.

> Существующие услуги без указанной ниши считаются общими — видны во всех филиалах.

### 3. Как работает таймлайн

| Ниша филиала | Колонки в таймлайне | Что отображается |
|---|---|---|
| AUTO | Сотрудники | Мастера с фото, графиком работы |
| BEAUTY | Сотрудники | Мастера с фото, графиком работы |
| RENT | Ресурсы | Объекты аренды (кабинеты, оборудование) с фото |

Переключение происходит **автоматически** при выборе филиала в шапке расписания.

### 4. Загрузка фото ресурса (для RENT)

CRM → Ресурсы → Открыть ресурс → секция фото вверху формы.

- **Загрузить** — выбрать файл, фото сожмётся автоматически.
- **Заменить** — загрузить новое фото (старое удалится).
- **Удалить** — убрать фото.
- Фото загрузить можно только после создания ресурса (сначала сохраните ресурс).

Фото отображается:
- В карточке ресурса в списке (мини-аватар)
- В колонке ресурса на таймлайне (вместо иконки-заглушки)

### 5. Создание записи в RENT-филиале

- В таймлайне отображаются колонки по объектам (ресурсам), а не по мастерам.
- При клике на пустой слот открывается форма записи. Поле «Ресурс» заполнено выбранным объектом.
- Список услуг фильтруется по нише — видны только RENT-услуги + общие.

---

## Для клиента (личный кабинет `/client`)

- При входе в личный кабинет выберите филиал в верхней панели.
- **В AUTO/BEAUTY филиале**: колонки по мастерам, выбор услуги, запись как обычно.
- **В RENT филиале**: колонки по объектам аренды (кабинеты, оборудование). Выбранный объект автоматически привязывается к записи.
- Услуги показываются с учётом ниши — только те, что подходят для этого филиала.

## Для разработчика

### Миграции БД

| Миграция | Изменение |
|---|---|
| `V41__Branch_Niche.sql` | `branches.niche VARCHAR(20) NOT NULL DEFAULT 'AUTO'` |
| `V42__Resource_Photo.sql` | `resources.photo_data BYTEA`, `resources.updated_at TIMESTAMP` |
| `V43__Service_Niche.sql` | `services.niche VARCHAR(20)` (NULL = все ниши) |

### Ключевые файлы

| Файл | Назначение |
|---|---|
| `nicheConfig.js` | Конфигурация лейблов, иконок, плейсхолдеров для трёх ниш |
| `nicheStore.js` | Svelte store: `activeNiche` derived from `activeBranchId` + `branchStore` |
| `ScheduleScreen.svelte` | Авто-переключение таймлайна по нише |
| `DayTimelineDesktop/Mobile.svelte` | Универсальные колонки через props `columns` + `columnKey` |
| `AppointmentEditScreen/Mobile/Desktop` | `formData.resourceId`, `preselected.resourceId`, фильтр услуг через `$activeNiche` |
| `ResourceEditScreen.svelte` | UI загрузки/удаления фото ресурса |
| `ServiceEditScreen.svelte` | Select ниши в редакторе услуги |

### API эндпоинты

| Эндпоинт | Метод | Описание |
|---|---|---|
| `/api/admin/resources/{id}/photo` | GET | base64 фото ресурса |
| `/api/admin/resources/{id}/photo` | POST | Загрузка фото (multipart) |
| `/api/admin/resources/{id}/photo` | DELETE | Удаление фото ресурса |
| `/api/client/resources?branchId=` | GET | Список ресурсов (для клиента) |
| `/api/client/resources/{id}/photo` | GET | base64 фото ресурса (для клиента) |
| `/api/services?niche=` | GET | Список услуг, опционально с фильтром по нише |
| `/api/client/services?branchId=` | GET | Услуги, отфильтрованные по нише филиала |
